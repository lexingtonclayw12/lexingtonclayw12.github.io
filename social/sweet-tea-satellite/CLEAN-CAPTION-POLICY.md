# Automatic publishing and clean-caption policy

User instruction, October 24, 2026: “yes pubish but publish automatically in the future. Ensure first no harsh language or cursing in the captions to adhere to social media standards and prevent any issues with the band itself.”

Standing approval covers routine Sweet Tea Satellite posts without per-post permission. Review all final captions and hashtags before publication: no profanity, cursing (including disguised/censored spelling), slurs, insults or harsh language. Keep copy warm, PG and welcoming. Check on-screen and spoken promotional copy too. Select a clean song passage if needed; never silently change lyrics or masters. Rewrite unsuitable promotional text and review again. Clean copy does not guarantee platform acceptance.

Before setting ready_for_publish, the reviewing agent must read the complete final caption and record caption_review with status=passed, policy=clean-caption-v1, a plain-language review note, reviewed_at and caption_sha256 of the exact UTF-8 caption string. This is a recorded semantic review, not an automatic profanity classifier. The publisher must reject missing reviews and hashes that no longer match the caption. Any edit requires a fresh review.

Retain identity, AI-label, public-audience, receipt and duplicate checks. Never retry an uncertain submission without reconciliation. Approval excludes comment replies, DMs, deletion, ads, other-client changes and release distribution. Reconcile Transmission numbering against actual posts before new creative assignments. Already approved test uses its exact approved caption.
